# BRIEF ส่ง Claude Code — Sync taxonomy หมวดหมู่เต็มจากชีต (204→205 หมวด)
เป้า: แทน `STOCK_CATEGORIES` ในโค้ด (ของเก่า 28 ตัว · stale + รหัสเพี้ยน) ด้วย **master taxonomy จริงจากชีต Mr.Chuti Stock (แท็บ Reference)** ครบ 204 หมวดย่อย/26 กลุ่ม + เพิ่ม `BDY-10 กาบบันได`
ไฟล์: `lib/docbrief-stock-categories.ts` (ไฟล์เดียว · data ล้วน) · main ล่าสุด
**ขอบเขต: แทนค่า array `STOCK_CATEGORIES` เท่านั้น · ห้ามแตะ `guessCategory` logic / CATEGORY_TERMS / ที่อื่น**

## ที่มา
ดึงจากชีตจริง (แท็บ Reference "26 หมวดหลัก, 204 หมวดย่อย") — โค้ดเดิมมีแค่ 28 และรหัสหลายตัวความหมายไม่ตรงชีตแล้ว (เช่น LGT-04 เดิม="ไฟเลี้ยว" แต่ชีต="ไฟเบรกดวงที่สาม" · DRR-04 เดิม="มือจับและล็อก" แต่ชีต="บานพับและตัวหยุดประตู") → auto-tag เดิมติดรหัสผิดความหมายได้ · แก้โดย sync ให้ตรงชีต
